## Run the Analysis

Python 3.10 or later is required. Python 3.12 was used for verification.
From this folder, use an environment with the packages in `requirements.txt`:

```bash
python -m pip install -r requirements.txt
python scripts/reproduce_statistics.py
python scripts/extract_image_features.py
python scripts/make_mask_previews.py
python scripts/plot_figures.py
python scripts/verify_repository.py
```

All paths default to this folder, not the current working directory. Pass
`--root /path/to/folder` and `--output-dir /path/to/new/output` to redirect data
or generated outputs. `verify_repository.py` uses `--output` for its JSON report.
Do not use the `data/` directory for generated outputs. Source inputs stay frozen.
The optional `--audit` plotting flag requires a separate panel-alignment helper
used during preparation; it is not needed by any normal command above.

For all raw survey frames stored as `RAW/condition_id/frame_id`, run:

```bash
python scripts/extract_image_features.py --raw-root /path/to/RAW --output-dir results/full_raw_check
```

Without `--raw-root`, only the six bundled raw examples are extracted. Stored
S0--S5 assignments are manually annotated input data and are not reassigned by
these scripts. Six examples illustrate the images and masks; the complete
processed tables retain all 3027 survey frames.

**Workflow:** each independent raw frame is converted to a jet-centered
grayscale ROI and contrast mask; the four silhouette features and left/right
measures are extracted, joined to frozen state labels, projected through the
fixed full-sample PCA transform, and aggregated/bootstrap-resampled by condition.

## Conditions, Units, and Orientation

`condition_id` retains the original `e-EXP_VOLTAGEv` folder name. Concentration
is `10**(-EXP)` mol/L, including half-decade exponents. Voltage is the original
laser calibration setting, not an additional independent experimental variable.
Concentration values use the full condition-level precision; some legacy
per-frame concentration exports had been rounded.

| Voltage (V) | Whole-beam incident pulse energy (mJ) |
|---:|---:|
| 770 | 6.5 |
| 775 | 13 |
| 780 | 20.5 |
| 785 | 31.5 |
| 795 | 56 |
| 810 | 84 |
| 850 | 114 |
| 915 | 168 |

Example: `e-3.5_785v` is `10**(-3.5)` mol/L at 31.5 mJ. Only the 32 rows in
`per_condition.csv` were sampled; the table is not a complete factorial grid.
`energy_mJ` is whole-beam incident energy, not intercepted or deposited heat.
Survey delay is 15 microseconds, supplied by the authors rather than recovered
from JPEG metadata. Image left is the incident side (-y); right is transmitted
(+y); imaging is perpendicular to the heating beam. Frames are independent
shots, not trajectories from a video. `frame_id` is the complete original file
name and is unique only **within** a condition. Join on both ID columns.

`ell_um` is the maximum **one-sided** connected span from the estimated jet
axis. It is already a half-span: do not divide it by two or interpret it as
velocity. The calibration is 5.63847153682089 micrometers/pixel. `a` is selected
exterior pixels divided by the full ROI area, not by the jet's projected area.
`ns` and `nc` are image-derived counts, not true bubble counts in three dimensions.

S0 is an intact silhouette; S1 isolated bubbles/small protrusions; S2 local
ejecta with a largely intact jet; S3 multisite structures; S4 strong jetting or
breakup; S5 a dense cloud without a clearly traceable continuous jet.
**All 3027 frames have manually annotated S0--S5 state labels.** Original file
names are retained solely as frame identifiers.

## PCA and Missing Values

Use the **full-precision** parameters in `metadata/pca_parameters.json`, not the
three-decimal loadings in the paper. For columns `x=(a,ell_um,ns,nc)`:

```text
z_j = (ln(1+x_j) - log_mean_j) / log_sample_sd_j
PC1 = sum(z_j * loading_j)
```

The logarithm is natural. The numerical length input is `ell/(1 micrometer)`;
changing to meters without transforming the parameters gives the wrong PC1.
For exact reproduction of the frozen manuscript transform, the executable
`feature_columns` are `a_PCA_input,ell_um_PCA_input,ns,nc`. The two `*_PCA_input`
columns preserve the actual archived CSV inputs, including their nonuniform
decimal/scientific-notation rounding. The primary `a` and `ell_um` columns are
reconstructed at full precision from stored pixel counts and calibration;
these reproduce the original condition feature means and standard deviations.
Do not silently substitute the count-derived fields into a frozen transform
that was fit to rounded export values. Both versions are retained for audit.

Sample deviations and covariance use `ddof=1`; all 3027 frames determine the
transform, without state labels. The four loadings are 0.497316354414317,
0.4464376828935409, 0.5237700104329676, and 0.5282374608977948. Explained variance
is 0.8582476499250866. PC1 has the all-positive sign convention and is not
refitted in condition bootstrap samples.

Blank CSV numeric fields are undefined/ineligible, **not zero**. Both `Ba` and
`Bl` are reported only when exterior area is positive (`mask_active=1`). For
those frames, `Ba=area_right/(area_left+area_right)` and
`Bl=span_right/(span_left+span_right)`. The published eligibility rule masks `Bl`
too, even if a zero-area frame has nonzero spans. A nonzero exterior mask is
not synonymous with S1--S5: some S0 frames have exterior pixels and some S1
frames contain internal features without exterior pixels.

`Ba_mean` and `Bl_mean` are **means of eligible per-frame ratios**, not ratios
of pooled areas/spans. `S_bar` and `PC1_mean` use all frames. A one-active-frame
condition has a degenerate percentile interval, not zero physical uncertainty.

## Masks and Bootstrap Settings

The executable algorithm is in `scripts/extract_image_features.py`; the frozen
settings are also listed in `metadata/image_processing.json`:

- Center and base width use up to the top 260 rows; base pixels are below 105;
  estimated width is clipped to 8--80 pixels, with a 24-pixel fallback.
- Remove the bottom 100 rows; the ROI extends at most 180 pixels either side
  of the estimated center. Preserve the original image scale.
- Background is Pillow Gaussian blur with radius 18 pixels; dark contrast is
  background minus grayscale. Use `contrast > clip(percentile_97,30,65)`.
- Follow the dark contiguous run nearest the axis if within
  `max(20,2*base_width)` pixels. Other rows are excluded from the exterior mask.
- Exclude the central band of half-width `max(5,int(.85*base_width))` pixels.
  Active axial rows need `max(3,int(.25*base_width))` exterior pixels and runs
  of at least two rows. Components use `mask[::4,::4]`, four-neighbor
  connectivity, and at least two sampled pixels per counted component.
- Bootstrap: 2000 whole-frame resamples with replacement, seed **20261115**,
  NumPy `default_rng`/PCG64; 2.5th and 97.5th percentiles with linear quantiles.
  Preserve `condition_order`, then draw for S, PC1, Ba, Bl; frame order is
  `row_index`. Changing ordering changes the finite-resample endpoints.

Intervals cover the available within-condition frame sample, not segmentation,
calibration, or annotation uncertainty. Figure 9(d) displays only conditions
with at least ten eligible exterior masks; **all** conditions remain in the
CSV, including smaller/empty active groups.

## Figure and Image Provenance

Figures 7--9 are rebuilt from the complete tables and the six exact manuscript
representatives. Figure 7 displays a common crop `(55,360,480,1320)` in original
pixel coordinates; the JPEGs in `examples/raw/` are full, byte-identical images.
Mask-preview PNGs are explicitly derived visualizations, not unprocessed data.
No intensity adjustment, color adjustment, or new label is applied to raw JPEGs.

Figure 3 uses **141 markers recovered from the original vector figure**, with
transmittance rounded to five decimal places in that recovered table. These
are not original energy-meter exports or individual-pulse replicates. The
paper's readings are instrument-averaged. Original instrument averaging counts
and uncertainties are unavailable here, so no synthetic error bars are added.
Connecting lines are visual guides, not fitted theory. Its rerendered layout
and colors differ from the unchanged reference PDF, while all recovered data
points are retained.

Figure 8's guide curves are model-derived constant-property thermal references,
not measured transition boundaries. They stop at the modeled concentration
range. The 190 degrees C guide is **not** an established spinodal. The optical
solver that produced those stored guide coordinates is outside this small
package; their plotting is reproducible, not a new physical validation.

Times New Roman is used when installed. On other systems a documented DejaVu
Serif fallback is used, or choose `--font "Your Font"`. PDF text remains editable;
font substitution or library changes may alter layout without changing the data.
`metadata/runtime_versions.json` records the actually tested environment.
